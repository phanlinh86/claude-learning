# Stock briefing

## Goal
Produce a short, sourced briefing on a stock: recent results, price moves and the news behind them.

## Status
Not started. Language, libraries and how to run it are still to be decided; update this file once they are.

## Rules for this project
- Keep all code for this project inside `projects/stock-briefing/`.
- The starting prompt is `shared/prompts/stock-briefing-hpq.txt`.
- Every number must come from a cited source; never estimate figures.
- Record how to install, run and test it in `README.md`.
