# PDF summarizer

## Goal
Take one or more PDFs and produce a clear summary of the key points.

## Status
Not started. Language, libraries and how to run it are still to be decided; update this file once they are.

## Rules for this project
- Keep all code for this project inside `projects/pdf-summarizer/`.
- Test on short PDFs first, then long and scanned ones.
- Record how to install, run and test it in `README.md`.
