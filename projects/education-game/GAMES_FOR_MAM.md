# Games for Mầm

Learning games made for Mầm with `/build-game-for-mam` (`.claude/skills/build-game-for-mam/`). Each one is a
long-form (≈ 30–40 min) iPhone/iPad web game with profiles, saved progress and score, English + Vietnamese voice that
says her name properly, funny sounds, and no losing. `/build-game-for-mam random [age] [hint]` rolls a new one and adds a
row here; the default profile is **Mầm, age 4** (parents can change the age 3–7+ behind the 2-second ⚙ hold).

Tip: in Safari tap **Share → Add to Home Screen** for a full-screen icon. For a Vietnamese voice on iOS:
Settings → Accessibility → Spoken Content → Voices → Vietnamese (download "Linh") — the game uses it for "Mầm" even in
English mode.
