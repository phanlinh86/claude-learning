# Search nhà Sài Gòn

## Goal
Find, vet and rank houses for sale in Ho Chi Minh City for a given location, minimum land area, budget and house type, and deliver an Excel list plus a PDF recommendation (1 main pick, top 10 alternatives, ads to avoid).

## Status
Working as a Claude skill: `.claude/skills/search-nha-sai-gon/SKILL.md` in this folder. No code yet; the Excel and PDF are built fresh on each run.

## Rules for this project
- Keep everything for this project inside `projects/search-nha-sai-gon/`.
- Every price, average and distance claim needs a source or an "est." label.
- Use both old and new ward names (HCMC merged wards on 1 July 2025).
- Record how to run it in `README.md`.
