# Search nhà Sài Gòn

A Claude skill that acts as an HCMC real-estate agent: it collects recent house ads, filters them by your criteria, sends research agents to check each house's nearest market, supermarket, primary school, hospital, flooding and safety, then delivers an Excel workbook and a PDF recommendation.

## How to run
Open Claude Code in this folder (`projects/search-nha-sai-gon/`) so the project skill loads, then ask:

```
Use the search-nha-sai-gon skill.
Location: Quận 3 (alley houses OK)
Area: more than 50 m²
Budget: 300,000 USD
Type: single-family house, at least 3 bedrooms, car access preferred
```

A run takes about 10–15 minutes.
