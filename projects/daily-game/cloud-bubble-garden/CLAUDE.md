# Nimbus's Bubble Garden (daily game, 2026-11-06)

## Goal
A family-friendly bubble popper in a rainy garden: Nimbus the cloud sprite floats after the finger/cursor, pops bubbles to collect gems, grows bigger with every 4 gems (more points, bigger target), bursts into a rain shower at full size, and dodges falling chestnut burrs, from dawn to night. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.NB` in `game/`. `world.js` is headless and deterministic (fixed 1/120 s steps); no camera (world = screen coords); sizes scale with `layout.unit`; `computeLayout(w, h, insets)` keeps the play area under the HUD.
- A Go + WebView2 wrapper in `app/` builds `dist/NimbusBubbleGarden.exe` (port 47623, then 47633/47643/47653).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content (burr bumps are soft "ouch-boings"; only falling burrs hurt), original art and sound only.
- Gems always differ by shape AND colour (round ruby, drop sapphire, square emerald, star topaz, heart amethyst).
- Storage keys use the `nbg:` prefix (all games share one GitHub Pages origin).
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
