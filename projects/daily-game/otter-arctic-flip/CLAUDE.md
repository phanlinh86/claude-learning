# Ollie's Lighthouse Flip (daily game, 2026-11-20)

## Goal
A family-friendly gravity-flip runner inside a cosy arctic lighthouse: Ollie the sea otter flips between the floor and the ceiling beam, avoids open hatches, snowball piles and hanging props, and catches fluttering greenhouse leaves while the four floors go from dawn to an aurora night (the visibility twist: darkness, wall lamps, warning beacons and a headlamp). Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Status
v1.0 integrated on 2026-11-20 (scaffolded from `../robot-rooftop-flip/`; colour matching removed, visibility twist added).

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.OF` in `game/`. `world.js` is headless and deterministic (fixed 1/120 s steps); horizontal scroll `cam.x`, no vertical camera; all sizes scale with `layout.unit`.
- Rendering: sky 0.03 / far 0.12 / back weather / mid (back wall with window holes) 0.6 parallax, pre-rendered pixel-exact tiles; darkness on a reused half-resolution canvas drawn from `world.lightView` (DESIGN §7); render interpolated with `world.alpha`; next floor pre-warmed; backing store capped (1920×1080 desktop, 3.2 MP touch) with adaptive quality.
- A Go + WebView2 wrapper in `app/` builds `dist/OlliesLighthouseFlip.exe` (port 47628).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules; `docs/MECHANICS.md` documents world/weather/bot.
- Kid-friendly content (bumps are soft boings, Pip the puffin rescues falls, the night is cosy), original art and sound only.
- Visibility rule: every hazard must be lit in time (beam = `world.beamUnits()`, beacons while `lampsOn`); never darker than 30 % light.
- Popups and callouts never cover Ollie; darkness is drawn under texts, HUD and banners.
- Storage keys use the `olf:` prefix (all games share one GitHub Pages origin).
- After changing `audio.js` / `index.html`, re-run `python3 shared/daily-mobile/apply.py otter-arctic-flip` (idempotent) and `test_extras.js`.
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
