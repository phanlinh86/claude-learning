# Clover's Farm Hop (daily game, 2026-11-08)

## Goal
A family-friendly vertical platform hopper: Clover the frog auto-bounces up a farm through 4 weather levels (sunny, rain, wind, snow), steering left/right, catching fireflies for her lantern, while wind gusts that change direction push her sideways. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.FH` in `game/`. `world.js` is headless, deterministic and pixel-free (1 u = 1 m; column 12 u wide; fixed 1/120 s steps; the camera `camY` lives in the world so falls are deterministic); `render.js` maps u → px (`unit` = VH/11.5 landscape, VW/12.8 portrait).
- A Go + WebView2 wrapper in `app/` builds `dist/CloversFarmHop.exe` (port 47731, then 47741/47751/47761).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content (falls are a soft trampoline "boing"), original art and sound only.
- `world.fireflies` is the live ARRAY; the caught count is `world.fireflyCount`.
- Storage keys use the `cfh:` prefix (all games share one GitHub Pages origin).
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
