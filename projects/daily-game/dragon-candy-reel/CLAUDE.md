# Taffy's Candy Reel (daily game, 2026-11-18)

## Goal
A family-friendly one-button fishing game with a timing reel, in candy land: Taffy the baby dragon fishes sugar snowflakes from a soda lake while wind gusts change direction. Requirement: `REQUIREMENT.md`. Made with `/build-game random`, scaffolded from `../panda-arctic-reel`.

## Status
v1.0, 2026-11-18.
- Built: new art (Taffy, snowflakes, sour gummies, windsock, four weather scenes), the wind twist in `world.js` (announced gusts, swaying hook, current), weather particles, bot, and the integration layer (renderer with wind-bowed line and windsock, audio with gust whoosh and per-level music moods, UI, storage, tests).
- Not yet verified: no one has listened to the music or played on a real iPhone/iPad (touch emulated in Chromium); the exe hasn't been run on Windows.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.PR` in `game/`. `world.js` is headless and deterministic (fixed 1/120 s steps, the wind on its own RNG stream); it gets the logical screen size and keeps the dock gap at `W/2`.
- A Go + WebView2 wrapper in `app/` builds `dist/TaffysCandyReel.exe` (port 47626).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- `game/js/extras.js` and the audio loudness patch come from `shared/daily-mobile/apply.py` (keep its markers in `audio.js`: `setVolume(v)` and `audioSession`).
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content, original art and sound only.
- Storage keys use the `dcr:` prefix (all games share one GitHub Pages origin); `extras.js` is loaded with `data-prefix="dcr:"`.
- Windows exe: `TaffysCandyReel.exe`, local port 47626, data in `%APPDATA%\TaffysCandyReel\data`.
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
