# Ember's Glow Castle (daily game, 2026-11-03)

## Goal
A family-friendly drop-and-merge puzzle in a cosy haunted-but-cute castle: Ember the baby dragon drops fireflies that merge into brighter lights, and Boo the helper ghost comes at combo 5. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Status
v1.0, built and tested on 2026-11-03.
- QA: functional (358/358 checks), visual and playtest reports are in `docs/reports/`. Applied: playtest CONFIG tuning (faster Easy goals, gentler Normal library/tower), layout caps so Ember fits on 4:3 landscape and the HUD fits on iPad portrait, wider portrait margins, non-overlapping celebration texts (keyed combo text, stacking, width-fitted), a lighter shorter level banner, magenta tier-3 fireflies (colour-blind check), distinct custom-picture ring colours, a calmer title screen, a rate-limited "refuse" sound, and seeded autorestart games that vary.
- Mechanics change found while building: with refuse-only rules nobody ever lost, so "night creeps" (pumpkins rising from the bottom every few drops) adds pressure from level 1 (Easy: level 2). See `docs/MECHANICS.md`.
- Not yet verified: no one has listened to the music or played on a real iPhone/iPad (touch emulated in Chromium); the exe hasn't been run on Windows.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.EG` in `game/`. `world.js` is headless and deterministic (fixed 1/120 s steps); it gets the logical screen size and centres a 5×7 board (6 rows on Hard).
- A Go + WebView2 wrapper in `app/` builds `dist/EmbersGlowCastle.exe` (port 47620).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content ("haunted" = cosy and funny), original art and sound only.
- Storage keys use the `egc:` prefix (all games share one GitHub Pages origin).
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
