# Momo's Dino Drums (daily game, 2026-11-16)

## Goal
A family-friendly rhythm tap game in the Dino Lookout tower: Momo the panda drums gems that hop in on the beat, and Pip the baby pterosaur helps at combo 5. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.DD` in `game/` (no build step). The world is screen-independent (lanes + times); `render.js` maps time to x and Pip's HELPER box to the screen.
- When audio runs, the AudioContext clock drives the world (no drift between music and judging).
- A Go + WebView2 wrapper in `app/` builds `dist/MomosDinoDrums.exe` (port 47624).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e (smoke, functional, mobile) and visual tests + player-model sims (`tests/sim/playtest.js`).

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules; tunables live in `DD.CONFIG` / `DD.DIFFICULTY` (`game/js/world.js`) and are documented in `docs/MECHANICS.md`.
- Kid-friendly content, original art and sound only.
- Storage keys use the `pdd:` prefix (all games share one GitHub Pages origin).
- `extras.js` comes from `shared/daily-mobile/`; it reads the shared DOM ids (`#scrOver #overScore #overBest #medal #medalName #overStats`), so keep them.
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
