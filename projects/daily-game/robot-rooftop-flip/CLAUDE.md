# Bolt's Rooftop Flip (daily game, 2026-11-05)

## Goal
A family-friendly gravity-flip runner over city rooftops: Bolt the robot pup flips between the roofs and an overhead sky-rail, avoids gaps, vents and hanging signs, and catches only the fireflies of his current colour (paint arches change it), from dawn to night. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.RF` in `game/`. `world.js` is headless and deterministic (fixed 1/120 s steps); horizontal scroll `cam.x`, no vertical camera; all sizes scale with `layout.unit`.
- A Go + WebView2 wrapper in `app/` builds `dist/BoltsRooftopFlip.exe` (port 47622).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content (bumps are soft boings, a drone rescues falls), original art and sound only.
- Firefly colours always come with a shape (pink heart, yellow star, blue drop) for colour-blind players.
- Storage keys use the `brf:` prefix (all games share one GitHub Pages origin).
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
