# Kit's Toybox Beat (daily game, 2026-11-01)

## Goal
A family-friendly rhythm tap game in a toy room. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Status
v1.0, built and tested on 2026-11-01.
- QA: functional (254/254), visual and playtest reports are in `docs/reports/`. Their P1/P2 fixes are applied, plus the playtest tuning (gentler Normal level 1, `wrongLaneMiss` anti-mash rule, Easy `maxDensity`).
- Not yet verified: no one has listened to the music or played on a real iPhone/iPad (touch emulated in Chromium); the exe hasn't been run on Windows.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.KB` in `game/`. The world is screen-independent (lanes + times); render.js maps time to x.
- When audio runs, the AudioContext clock drives the world (no drift between music and judging).
- A Go + WebView2 wrapper in `app/` builds `dist/KitsToyboxBeat.exe` (port 47618).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content, original art and sound only.
- Storage keys use the `ktb:` prefix (all games share one GitHub Pages origin).
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
