# Spike's Dino Jam (daily game, 2026-10-31)

## Goal
A family-friendly, snake-style trail grower in a dinosaur valley. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Status
v1.0, built and tested on 2026-10-31.
- QA: functional, visual and playtest reports are in `docs/reports/`. Their P1/P2 fixes are applied, plus the recommended Easy/Normal tuning, `bounceGrace` and `targetDead`.
- Not yet verified: the game hasn't been played on a real iPhone or iPad (touch was emulated in Chromium with CDP touch events), and the exe hasn't been run on Windows.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.DJ` in `game/`.
- A Go + WebView2 wrapper in `app/` that builds `dist/SpikesDinoJam.exe` (port 47617).
- Original SVG art, generated by `tools/art-*`.
- Sound synthesized with WebAudio. Every collected note plays the next note of the biome's tune.
- Node unit tests + Playwright e2e tests.

## Layout notes
- World coordinates = logical canvas coordinates. The renderer computes the arena from the screen, the safe areas and the HUD band, and calls `World.setArena()` on every relayout.
- The static background (tiled ground, rotated border strips, decor) is pre-rendered once per biome and size, then blitted pixel-exact.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content, and original art and sound only.
- Storage keys use the `sdj:` prefix, because every game shares one GitHub Pages origin.
- `app/web/`, `build/` and `dist/` are build outputs and are gitignored.
