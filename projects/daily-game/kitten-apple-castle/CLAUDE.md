# Ziggy's Apple Castle (daily game, 2026-11-19)

## Goal
A family-friendly drop-and-stack physics tower at a cosy haunted-but-cute castle: Ziggy the rocket kitten drops apple crates from her hover-rocket, catches floating apples (5 apples = a pie = +1 heart), and fills each time of day's crate goal so Granny Boo the friendly ghost can fetch the apples. The twist: the day turns to night as the tower grows; Perfect drops hang lanterns that light the way. Requirement: `REQUIREMENT.md`. Made with `/build-game random`, scaffolded from `../fox-moon-stack`.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.AC` in `game/`. `world.js` is headless and deterministic (fixed 1/120 s steps), world coords with a camera (`cam.y`); all sizes scale with `layout.unit`.
- `render.js` draws a ½-resolution darkness layer over the scene with soft holes for every `world.lights()` entry, then the glow things (window glints, moon, lanterns, glow apples, fireflies) and the HUD (DESIGN §6).
- A Go + WebView2 wrapper in `app/` builds `dist/ZiggysAppleCastle.exe` (port 47627).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content (topples are soft tumbles, nothing scary, night is never black), original art and sound only.
- Storage keys use the `kac:` prefix (all games share one GitHub Pages origin).
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
