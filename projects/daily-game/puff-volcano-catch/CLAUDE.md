# Puff's Volcano Catch (daily game, 2026-10-30)

## Goal
A family-friendly basket catcher set on a volcano island. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Status
v1.1 adds the mobile layer for iPhone and iPad (2026-10-31, same approach as `projects/education-game/`).
- Tests: 23/23 unit, 230/230 functional, 98/98 mobile, 562/562 mobile QA, with a clean smoke run.
- QA: the desktop visual QA and playtest fixes, plus the mobile functional and visual QA P1/P2 fixes, are applied.
- Not yet verified: the game hasn't been played on a real iPhone or iPad (touch was emulated in Chromium with real CDP touch events), and the exe hasn't been run on Windows.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.VC` in `game/`.
- A Go + WebView2 wrapper in `app/` that builds `dist/PuffsVolcanoCatch.exe` (port 47616).
- Original SVG art, generated by `tools/art-*`.
- Sound synthesized with WebAudio.
- Node unit tests + Playwright e2e tests.

## Mobile layout (render.js `computeView` / `resize`)
- Logical canvas: landscape ≥ 16:9 is 540 tall and up to 1280 wide; 4:3-ish landscape is 960 wide with a taller sky; portrait is 560 wide (720 on tablets) and up to 1600 tall.
- The 960×540 scene is bottom-anchored and centred: all gameplay stays in scene coordinates, and `toLogical()` returns scene coordinates.
- Safe-area insets are read from `#safeProbe`. `World.setPlayRange()` gets the shore Puff can reach on this screen, so coins only land there and flying ones are re-aimed after a rotation.
- The HUD is drawn in screen space. The pouch moves to a second row on narrow screens.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content, and original art and sound only.
- Storage keys use the `pvc:` prefix, because every game shares one GitHub Pages origin.
- `app/web/`, `build/` and `dist/` are build outputs and are gitignored.
