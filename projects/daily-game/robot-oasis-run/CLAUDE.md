# Pebble's Oasis Run (daily game, 2026-11-07)

## Goal
A family-friendly pseudo-3D 3-lane runner: Pebble the robot pup runs into the screen through 4 storybook chapters of a desert oasis, changes lanes, jumps logs/tumbleweeds/pillows, collects seashells, and dodges the pillows that Fizz the fennec (on a flying carpet) throws every 30 s. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.PO` in `game/`. `world.js` is headless, deterministic and pixel-free (1 u = one lane width; fixed 1/120 s steps); `render.js` projects (x, y, z) with a simple camera (`CAM {h 1.9, d 3.2}`), sprites on a ×1.25 size ladder.
- A Go + WebView2 wrapper in `app/` builds `dist/PebblesOasisRun.exe` (port 47671, then 47681/47691/47701).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content (bumps are soft "boing"/"fwump"), original art and sound only.
- Shells differ by shape AND colour (pink scallop, peach conch, lilac cowrie).
- Storage keys use the `por:` prefix (all games share one GitHub Pages origin).
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
