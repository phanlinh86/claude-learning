# Juno's Moon Stack (daily game, 2026-11-04)

## Goal
A family-friendly drop-and-stack physics tower in outer space: Juno the little fox drops cargo crates from her hover-saucer, grabs star-coins to grow bigger, and fills each planet's crate goal so a rocket takes her to the next planet. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Status
v1.0, built and tested on 2026-11-04.
- QA: unit 23/23, functional 261 checks, visual and playtest reports in `docs/reports/`. Applied: playtest CONFIG tuning (Easy for real 4–6-year-olds, more beam assist so topples are rarer, fairer Hard perfects, gentler loops), Easy never shrinks Juno, longer goal show with Juno boarding the rocket, HUD panels fade when the saucer flies under them, banner/hint moved to the ground strip, shape-coded Easy drop guide, additive tractor beam, no grey halo discs on sky stars, custom crate pictures default to "whole picture", focused Menu button + Enter no longer restarts, HUD best per run difficulty, browser fallback of the exe without `?app=1`.
- Not yet verified: nobody has listened to the music or played on a real iPhone/iPad (touch emulated in Chromium); the exe hasn't been run on Windows.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.MS` in `game/`. `world.js` is headless and deterministic (fixed 1/120 s steps), world coords with a camera (`cam.y`); all sizes scale with `layout.unit`.
- A Go + WebView2 wrapper in `app/` builds `dist/JunosMoonStack.exe` (port 47621).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content (topples are soft tumbles, nothing scary), original art and sound only.
- Storage keys use the `jms:` prefix (all games share one GitHub Pages origin).
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
