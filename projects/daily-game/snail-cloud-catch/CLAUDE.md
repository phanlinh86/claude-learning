# Shelly's Sky Catch (daily game, 2026-11-15)

## Goal
A family-friendly basket catcher in a cloud kingdom: Shelly the jetpack snail catches falling stars through four weather levels. Requirement: `REQUIREMENT.md`. Made with `/build-game random`. The integration code and the mobile layer were adapted from the sister catcher `../puff-volcano-catch`.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.SC` in `game/`.
- A Go + WebView2 wrapper in `app/` that builds `dist/ShellysSkyCatch.exe` (port 47623).
- Original SVG art, generated by `tools/art-*`.
- Sound synthesized with WebAudio (no audio files).
- Node unit tests + Playwright e2e tests.

## Modules
- Mechanics: `rng.js`, `world.js` (`SC.CONFIG`, `SC.DIFFICULTY`, `SC.ZONES`, `SC.World`), `weather.js`, `bot.js`.
- Integration: `storage.js`, `assets.js`, `audio.js`, `render.js`, `ui.js`, `main.js`, `extras.js` (shared copy: volume slider + Score Card).
- `docs/DESIGN.md` is the contract: asset names (§4), World fields and events (§5.1), Weather (§5.2), Bot (§5.3), test hooks (§5.4), mobile (§8).

## Mobile layout (render.js `computeView` / `resize`)
- Logical canvas: landscape ≥ 16:9 is 540 tall and up to 1280 wide; 4:3-ish landscape is 960 wide with a taller sky; portrait is 560 wide (720 on tablets) and up to 1600 tall.
- The 960×540 scene is bottom-anchored and centred: all gameplay stays in scene coordinates, and `toLogical()` returns scene coordinates.
- Safe-area insets are read from `#safeProbe`. `World.setPlayRange()` gets the part of the cloud floor Shelly can reach on this screen, so stars only drop there.
- The HUD is drawn in screen space. The star jar moves to a second row on narrow screens.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content, and original art and sound only.
- Storage keys use the `ssc:` prefix, because every game shares one GitHub Pages origin.
