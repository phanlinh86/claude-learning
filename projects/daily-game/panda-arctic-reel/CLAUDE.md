# Bao's Arctic Reel (daily game, 2026-11-02)

## Goal
A family-friendly one-button ice-fishing game with a timing reel, in the arctic. Requirement: `REQUIREMENT.md`. Made with `/build-game random`.

## Status
v1.0, built and tested on 2026-11-02.
- QA: functional, visual and playtest reports are in `docs/reports/`. Applied: visual P1/P2 fixes (catch arc over Bao's head, portrait HUD in the sky, readable first-zone hint, tint under the items, gem glow, reel label/feedback, visible cut hook), functional fixes (adaptive quality measures work time and recovers; Menu restart lock; leftover CSS), playtest tuning (gentler needle speed-up and green-zone shrink per zone on Normal/Hard) and Easy as the first-run default.
- Not yet verified: no one has listened to the music or played on a real iPhone/iPad (touch emulated in Chromium); the exe hasn't been run on Windows.

## Stack
Same as the other games in `projects/daily-game/`:
- HTML5 canvas + plain JS on `window.PR` in `game/`. `world.js` is headless and deterministic (fixed 1/120 s steps); it gets the logical screen size and keeps the hole at `W/2`.
- A Go + WebView2 wrapper in `app/` builds `dist/BaosArcticReel.exe` (port 47619).
- Original SVG art generated by `tools/art-*`; sound synthesized with WebAudio.
- Node unit tests + Playwright e2e/visual tests + player-model sims.

## Rules
- Keep all code inside this folder. `docs/DESIGN.md` is the contract between modules.
- Kid-friendly content, original art and sound only.
- Storage keys use the `par:` prefix (all games share one GitHub Pages origin).
- `app/web/`, `build/`, `dist/` and `tests/out/` are build outputs and are gitignored.
