# Flappy

## Goal
A small Flappy Bird–style game: a bird flaps through gaps between pipes and scores a point per gap.

## Status
Not started. Language, libraries and how to run it are still to be decided; update this file once they are.

## Rules for this project
- Keep all code for this project inside `projects/flappy/`.
- Start with the simplest playable version (bird, pipes, collision, score), then add polish.
- Record how to install, run and test it in `README.md`.
